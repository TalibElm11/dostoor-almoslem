# دستور المسلم العملي — النسخة التأسيسية

موقع تعليمي عربي باتجاه RTL، يعمل كصفحة ويب ثابتة دون خادم أو قاعدة بيانات.

## الملفات
- `index.html`: بنية الصفحات والمحتوى.
- `styles.css`: التصميم والألوان والتجاوب مع الهاتف.
- `app.js`: قائمة الهاتف والبحث التجريبي ومتابعة التدريب الأسبوعي.

## التشغيل محليًا
افتح `index.html` مباشرة في متصفح حديث. يحتاج تحميل خط Cairo وAmiri إلى اتصال بالإنترنت؛ توجد خطوط بديلة عند عدم توفره.

## النشر المجاني
يمكن رفع الملفات إلى GitHub ثم نشر المستودع باستخدام GitHub Pages، أو رفعها إلى Cloudflare Pages. راجع حدود وشروط الخطة المجانية الحالية لدى مزود الاستضافة قبل النشر.

## ملاحظات مهمة قبل النشر العام
1. هذه نسخة تأسيسية وليست مراجعة شرعية نهائية.
2. يجب مراجعة نصوص الآيات ومطابقتها للمصحف المعتمد، ومراجعة تخريج الأحاديث وألفاظها.
3. الأبواب التي تحمل عبارة «قريبًا» هي هيكل تنقل أولي وتحتاج إلى بناء محتواها.
4. البحث الحالي تجريبي ويبحث في مجموعة نصوص محدودة داخل الصفحة، وليس محرك بحث شاملًا.
5. لا توجد حاليًا لوحة إدارة أو حسابات مستخدمين أو قاعدة بيانات.
